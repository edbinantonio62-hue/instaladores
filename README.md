# 🚀 Guía Rápida de PSeInt

![PSeInt](https://img.shields.io/badge/PSeInt-Educativo-blue?style=for-the-badge)
![Plataformas](https://img.shields.io/badge/Windows--Linux--macOS-brightgreen?style=for-the-badge)

**PSeInt** es un entorno sencillo para aprender la lógica de la programación mediante pseudocódigo en español.

---

## 📥 1. Instalación

* 🪟 **Windows:** Descarga el ejecutable (`.exe`) desde [pseint.sourceforge.net](https://pseint.sourceforge.net/) y ejecútalo.
* 🐧 **Linux:** Descomprime el paquete `.tar.gz` y ejecuta `./pseint` en la terminal.
* 🍎 **macOS:** Abre el archivo `.dmg` y mueve la app a **Aplicaciones**.

---

## ⚙️ 2. Configuración Inicial

Al abrir PSeInt por primera vez, elige tu perfil:
* 🟢 **Flexible:** Ideal si estás comenzando (no exige `;` ni sintaxis estricta).
* 🟡 **Estricto:** Exige reglas rigurosas (ideal si luego pasarás a C++, Java o C#).

---

## 💻 3. Hola Mundo

Copia este código en el editor:

```pseint
Algoritmo HolaMundo
	Escribir "¡Hola, mundo! 🚀"
FinAlgoritmo

```

Haz clic en el botón de **Play ▶️** para ver el resultado en pantalla.

---

## 🛠️ Funciones Clave

* 👣 **Paso a Paso:** Ejecuta el código línea por línea para ver cómo funciona.
* 🌳 **Diagrama de Flujo:** Convierte tu código en un diagrama visual de forma automática.
* 🔄 **Exportar:** Guarda tu programa directamente en Python, C++, Java o JavaScript (`Archivo > Exportar`).
